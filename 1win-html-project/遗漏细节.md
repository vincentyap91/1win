## 还遗漏的设计与前端状态

1. **动态内容基准。** 轮播内容会换；人数、游戏数量、奖金和倒计时会更新。本地人数和倒计时保留截图值；轮播自动切换的真实时序、拖动手感未完全测量。预览地址加 `?qa=1` 可停用自动轮播以复查截图。
2. **弹窗的完整状态。** 默认登录／注册、Phone／Email 登录、Phone 密码恢复、注册优惠码展开已有原站样本。错误、成功、验证码、密码显示、币种列表、电话地区列表、生日选择、Email 恢复等尚未全面对照。手机 Login 使用已观察的组件样式适配，没有独立原站手机 Login 截图验收。
3. **菜单与页脚。** 手机菜单隐藏时不能挡住点击；打开时背景宽度应保持。当前已修正。菜单图标复用同一原站桌面图标；菜单打开、桌面缩小侧栏、页脚展开没有独立原站状态截图比较。桌面缩小侧栏目前是本地简化状态。
4. **语言、币种和地区差异。** 已保存语言选择器的外观，但 33 个语言／地区旗帜未取得；并未复制所有语言翻译或地域版本。选择器不会将整页伪装为已翻译。人民币版、中文版以及不同地区的内容需另有原站基准。
5. **其他页面的图片与验收。** Casino 等页面已接入本地导航并检查桌面首屏，Blog 和 Betwave 仍有明显缺图。它们没有全部五尺寸、全页及全部状态的逐像素对照。`qa/missing-visible-images.json` 和 `qa/page-browser-checks.json` 记录当前缺口。
6. **未取得完整页面证据。** Sports／Markets 仅见加载状态，Trading 仅见账户入口；Forum、Poker、Rules、赛事详情、活动详情、博客文章、全部游戏分类和游戏详情尚未实现完整设计。不能将这些链接或抓取到的加载画面算作完成。
7. **响应式中间尺寸。** 五个指定尺寸已比较。中间宽度有自适应与轮播缩放，但仍需要对照原站检查断点两侧、长文本、浏览器缩放、真实手机键盘和安全区。
8. **持续维护。** 本地 DOM／CSS 是 2026-10-13 观察到的页面状态。活动结束、图标或布局更新后，原站和本地会自然产生差异。
9. **打开方式。** 已验证本机 HTTP 预览；浏览器工具不允许 file:// 协议，直接打开 HTML 的运行方式未验证。使用随附启动器即可运行已验证的方式。
